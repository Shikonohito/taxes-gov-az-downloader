# taxes-gov-az-downloader

Скрипт открывает личный кабинет `new.e-taxes.gov.az`, помогает пройти вход через
Asan İmza, выбирает кабинет по VÖEN и скачивает два Excel-файла:

- `Qaimələr üzrə`;
- `Ödəyicilər üzrə`.

PIN1 не хранится и не вводится программой: когда Asan İmza пришлёт запрос,
подтвердите код и введите PIN1 на телефоне. После этого скрипт продолжит работу
самостоятельно.

## Установка

Требуется Node.js 20 или новее.

```powershell
npm install
npx playwright install chromium
Copy-Item .env.example .env
```

Откройте `.env` и задайте:

```dotenv
ASAN_PHONE=501234567
ASAN_USER_ID=123456
TAXPAYER_TIN=1234567890
```

- `ASAN_PHONE` — девять цифр после `+994`;
- `ASAN_USER_ID` — шестизначный ID Asan İmza;
- `TAXPAYER_TIN` — VÖEN кабинета, который нужно открыть.

`.env` и профиль браузера исключены из Git. Тем не менее `.env` содержит
чувствительные данные, поэтому не передавайте этот файл другим людям.

## Запуск

```powershell
npm start
```

При первом запуске или после истечения сессии:

1. Скрипт заполнит форму Asan İmza и отправит запрос.
2. На телефоне подтвердите совпадение кода и введите PIN1.
3. Скрипт выберет кабинет с указанным `TAXPAYER_TIN`.
4. Файлы появятся в каталоге `downloads`.

Для браузера используется отдельный постоянный профиль `.browser-profile`.
Пока серверная сессия действительна, повторный вход через телефон не нужен.
Не запускайте одновременно две копии программы с одним профилем.

## Настройки

Дополнительные переменные из `.env.example`:

- `DOWNLOAD_DIR` — каталог для файлов, по умолчанию `downloads`;
- `BROWSER_PROFILE_DIR` — каталог отдельного профиля;
- `BROWSER_CHANNEL` — `chromium`, `chrome` или `msedge`;
- `AUTH_TIMEOUT_MS` — время ожидания действий на телефоне;
- `DOWNLOAD_TIMEOUT_MS` — время ожидания формирования каждого Excel-файла;
- `SLOW_MO_MS` — задержка между действиями для диагностики.

Если `TAXPAYER_TIN` не задан, после подтверждения PIN1 кабинет нужно выбрать
вручную; затем скрипт продолжит загрузку.
